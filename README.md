Esta es la actividad individual n°2, el módulo docente

Tecnologías emergentes, universidad de manizales
Pablo Nieto Pérez

Panel administrativo hecho con vite, react y material ui a partir del proyecto inicial de la materia, tiene el módulo de estudiantes que se hace en la guía de clase y el módulo de profesores que pide la actividad, con el listado, el formulario para crear y editar y la opción de eliminar

Para correrlo se usa npm install y luego npm run dev

Está en línea en https://docente.wib.digital
